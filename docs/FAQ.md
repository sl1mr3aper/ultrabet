# FAQ

### Откуда берутся данные?

Все спортивные данные приходят из публичного API [SStats.net](https://sstats.net).
UltraBet не парсит сторонние сайты и не использует букмекерские API напрямую.

### Что такое xG?

Expected goals — ожидаемые голы. Сумма xG-значений всех ударов команды по
формуле, учитывающей позицию, тип удара, ассистента и т.п. Это объективнее, чем
просто счёт.

### Что значат проценты в Топ-15?

Это вероятность исхода рынка по версии нашей модели (Glicko-2 + Poisson).
Например 64% на ТБ 1.5 = модель оценивает шанс трёх и более голов в матче в 64%.

### Что такое EV?

Это разница между нашей оценкой и тем, что предлагает рынок. Если по нашей
вероятности справедливый коэф 1.85, а букмекер даёт 2.10, то EV ≈ +13.5%.

### Гарантия выигрыша?

Нет. Любая прогнозистическая модель — оценка вероятности. Даже EV-ставки
проигрывают на короткой дистанции. UltraBet — инструмент аналитики, а не
машина для печати денег.

### Можно ли использовать модель в проде?

Да, открытый код, MIT-лицензия. Но нужно взять у SStats production-ключ
для повышенной квоты.

### Как сообщить об ошибке?

`/feedback` в боте, или Issue на GitHub. Описывай шаги воспроизведения.

### Поддерживается ли английский?

Пока полностью русскоязычный интерфейс. Локализация — на дорожной карте.
См. `docs/ROADMAP.md`.

### Как часто обновляется база?

- Список матчей — каждые 15 минут (внутренний кэш).
- Glicko-рейтинги — каждые 10 минут.
- Коэффициенты — каждые 3 минуты для прематча, в реальном времени для лайва.
