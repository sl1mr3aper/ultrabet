# Возможности UltraBet

Полный перечень того, что бот умеет.

## Основные сценарии

### 1. Прогноз на матч

`/match Команда1 - Команда2` или кнопка «🎯 Прогноз». Бот:

1. Парсит запрос.
2. Подбирает кандидатов по обоим командам через `/Teams/list`.
3. Если есть несколько похожих — спрашивает страну (на русском с флагом).
4. Подтягивает `/Games/glicko/{id}`, `/Games/{id}`, `/Odds/{id}` параллельно.
5. Считает ансамбль 40+ рынков.
6. Возвращает отчёт: топ-15, точные счёта, xG, топ-5 валуйных.

### 2. Очные встречи (`/h2h`)

Берёт последние 10 матчей пары команд через `POST /Games/query`, считает
доли побед, средний тотал, BTTS-rate.

### 3. Daily picks (`/dailypicks`)

Запускает скан всех матчей дня (`/Games/list?Today=true`), для каждого
строит прогноз, фильтрует по `min_value_percent`, сортирует по EV, возвращает топ-10.

### 4. Топ матчей (`/top`)

Ранжирует матчи дня по престижу лиги (см. `LEAGUE_PRESTIGE`) и среднему
рейтингу команд. Удобно для выбора, на что вообще смотреть.

### 5. Карточка команды (`/team`)

Glicko-рейтинг, страна, лига, последние 10 матчей, ближайшие 5.

### 6. Карточка игрока (`/player`)

Имя, позиция, гражданство, возраст, команда, последние события (голы, ассисты, карточки).

### 7. Турнирная таблица (`/standings`)

Берёт текущий сезон через `/Ls/Seasons` и подгружает `/Seasons/standings`.

### 8. Личный профиль (`/profile`, `/me`, `/history`)

История запросов, количество прогнозов, остаток квоты, тип подписки.

## Платёжная инфраструктура

- Подписки `1d`, `1w`, `1m`, `3m`, `12m` — настраиваемые в `services/subscription_service.py`.
- Лог всех платежей в `db.PaymentLog`.
- Реферальная программа: `+3` за приведённого, `+5/+15/+45` за подписку.
- Админ-команда `/grant <tg_id> <plan>` для ручной активации.

## Аналитический инструментарий

- Калькулятор Kelly (`/calc <bankroll> <prob> <odds>`).
- Анализатор формы команды (`core.form_analyzer.analyze_form`).
- Индекс моментума (`core.momentum.compute_momentum`).
- Line-shopping для сравнения коэффициентов разных букмекеров.

## Админка

- `/admin` — статистика приложения.
- `/grant`, `/ban`, `/unban`, `/broadcast`, `/notify`.
- Глобальный счётчик через `services.stats_aggregator.StatsAggregator`.

## Inline-кнопки

Все основные сценарии доступны не только через slash-команды, но и через
главное меню (см. `bot/keyboards.py:main_menu_keyboard`).
