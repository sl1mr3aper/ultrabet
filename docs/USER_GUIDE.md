# Гайд по использованию UltraBet

## Команды

| Команда | Что делает |
|---------|-----------|
| `/start` | Регистрация и главное меню |
| `/menu` | Главное меню |
| `/help` | Справка по командам |
| `/match Команда1 - Команда2` | Прогноз на матч (или через кнопку «🎯 Прогноз») |
| `/h2h Команда1 - Команда2` | Очные встречи команд |
| `/team Название` | Карточка команды (рейтинг, последние/ближайшие матчи) |
| `/player Имя` | Карточка игрока |
| `/top` | Топ-10 матчей дня по значимости |
| `/dailypicks` | Топ-10 валуйных ставок дня |
| `/league` | Список лиг |
| `/standings` | Турнирная таблица выбранной лиги |
| `/today`, `/tomorrow`, `/live` | Списки матчей |
| `/subscribe` | Подписки и тарифы |
| `/referral` | Личная реферальная ссылка |
| `/balance` | Остаток квоты |
| `/profile` | Личный профиль и история |
| `/feedback` | Отправить обратную связь |

## Прогноз: что внутри

Каждый отчёт содержит:

1. Шапка: команды, дата, лига, страна (на русском), рейтинги Glicko-2.
2. **Топ-15 рынков** по вероятности из 40+ рассчитанных.
3. **Вероятные точные счета** (топ-5).
4. **xG-анализ**: ожидаемые голы по командам, общий тотал.
5. **Топ-5 валуйных** ставок: только если рассчитанная вероятность даёт +EV
   против реальных коэффициентов с биржи.
6. Остаток бесплатных запросов.

## Подписки

Тарифы в `services/subscription_service.py`:

- 1 день — для разовых запросов.
- 1 неделя — для активных уикендов.
- 1 месяц / 3 месяца / 12 месяцев — длительные подписки с увеличенной квотой.

## Реферальная программа

- За каждого пользователя по твоей ссылке: `+3` бесплатных прогноза.
- Если он оформит подписку: `+5` (1 мес), `+15` (3 мес), `+45` (12 мес) бонусных прогнозов.

## Ограничения

- Ежедневная квота сбрасывается каждые 24 часа.
- При превышении лимита — предложение оформить подписку.
- Заблокированные пользователи получают `BLOCKED_NOTICE` (см. `bot/texts.py`).
