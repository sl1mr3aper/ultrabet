# Дорожная карта

## v0.2 (ближайшие)

- [ ] Локализация: английский язык.
- [ ] Webhook вместо long-polling, продакшен-готовая конфигурация.
- [ ] Перенос на PostgreSQL + alembic миграции.
- [ ] Notifications: подписка на матч, оповещения за 30 мин до старта.
- [ ] Live-режим: `/live` с обновлением через `editMessageText`.
- [ ] OAuth-связка для платных подписок (YooKassa / Stripe).

## v0.3

- [ ] Backtesting: сравнение модели с реальными результатами на исторических данных.
- [ ] Доп. рынки: угловые, карточки, голы по таймам.
- [ ] Оптимизация ансамбля: динамический weight по лиге/сезону.
- [ ] User-defined фильтры: «показывать только КЛ», «без тоталов» и т.п.

## v1.0

- [ ] Web-панель администратора (отдельный проект).
- [ ] Bandit-/AB-тестирование коэффициентов веса моделей.
- [ ] Bayesian-update Glicko после каждого матча для тонкой настройки.

## Отложено

- Crypto-платежи: ожидаем стабилизации регулирования.
- Marketplace «купить пик у топ-аналитика»: требует юридической проработки.
