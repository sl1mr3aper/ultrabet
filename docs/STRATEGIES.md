# Стратегии ставок — руководство

Подробное описание всех поддерживаемых стратегий с примерами, математикой и
рекомендациями.

## Общие принципы

### Вероятность vs коэффициент

- **Model probability** (p) — наша оценка вероятности события (0..1).
- **Bookmaker implied probability** — 1/odds. Включает маржу букмекера.
- **Fair odds** — 1/p, то есть коэф без маржи.
- **Value** — (p × odds − 1). Положительная ⇒ матожидание прибыли в среднем.

### Правило Келли

Оптимальная доля банка:

    f* = (b·p − q) / b
    
где b = odds − 1, p — вероятность, q = 1 − p.

**Проблемы Kelly в чистом виде**:
- высокая волатильность;
- при переоценке p легко обнулиться;
- моральное давление огромных стейков.

Поэтому **дробный Kelly**: f = k · f*, k ∈ {0.25, 0.5}.

## Стратегии в UltraBet

### 1. Conservative — Консервативная

**Параметры**:
- probability ≥ 0.55
- odds ∈ [1.25, 2.20]
- value ≥ 2.0 %
- top-5 прогнозов

**Для кого**: хочешь стабильность, готов на низкую прибыль ради ровной кривой.
**Типичный ROI**: 3–7 % (на длинных сериях, 500+ ставок).
**Stake**: Half-Kelly или Percent 1–2 %.

### 2. Balanced — Сбалансированная (по умолчанию)

**Параметры**:
- probability ≥ 0.35
- odds ∈ [1.50, 4.50]
- value ≥ 5.0 %
- top-5 прогнозов

**Для кого**: ищешь баланс между частотой, риском и прибылью.
**ROI**: 5–15 %.
**Stake**: Half-Kelly, Quarter-Kelly.

### 3. Aggressive — Агрессивная

**Параметры**:
- probability ≥ 0.18
- odds ∈ [3.0, 15.0]
- value ≥ 8.0 %
- top-5 прогнозов

**Для кого**: готов к крупной волатильности ради большой прибыли.
**ROI**: 10–30 % (но и −20..−40 % drawdowns возможны).
**Stake**: Flat 1–2 %, или Quarter-Kelly.

### 4. Underdog — Андердог

**Параметры**:
- probability ≥ 0.10
- odds ∈ [4.0, 30.0]
- value ≥ 15.0 %
- top-3 прогнозов

**Для кого**: охотник за большими коэф. Крупные провалы между редкими
выигрышами — это нормально.
**ROI**: 15–50 %, но с drawdown до 60 %.
**Stake**: Quarter-Kelly только. Никогда не full Kelly.

## Mana ging bankroll

### Flat stake
- Всегда одинаковая сумма (например, 1 % от начального банка).
- Плюсы: просто, предсказуемо.
- Минусы: не использует преимущество при больших эджах.

### Percent stake
- Фиксированный % от текущего банка (1–3 %).
- Плюсы: сам скейлится с банком.
- Минусы: всё ещё не учитывает `value`.

### Kelly / Half / Quarter
- Максимизирует geometric growth.
- Цифры зависят от оценки p — не подходит плохо откалиброванной модели.

### Martingale — удваивание после loss
- Plan: после проигрыша удваиваем ставку, чтобы отыграться.
- Реальность: **убийственно** при чёрной полосе. Cap max_fraction = 10 % банка.
- Используй только на коротких сериях (до 4 ставок подряд).

### Anti-Martingale — удвоение после выигрыша
- Добавляем к ставке после выигрыша, чтобы "ехать" волну.
- Безопаснее, чем classic martingale, но тоже бывают провалы.

## Правила для любой стратегии

1. **Никогда не ставь всё на один исход** — даже при 99 % вероятности.
2. **Лимитируй max_fraction** — не более 10 % банка на одну ставку
   (в идеале ≤ 5 %).
3. **Регулярно переоценивай банк** — не каждую ставку, а раз в
   неделю/месяц, чтобы избежать ложных сигналов.
4. **Записывай каждую ставку** (используй `/journal` в боте) — без журнала
   невозможно понять, работает ли твоя стратегия.
5. **Оценивай hit-rate против implied probability** модели.
   Если hit-rate ниже, чем p говорит — значит модель переоценивает шансы,
   отрицательный ROI неизбежен.

## Как выбирать параметры

- **Недели 1–4**: используй Conservative + Flat 1 %. Запиши каждую ставку.
- **После 50 settled ставок**: считай свой ROI. Если >5 %, переходи
  на Balanced + Half-Kelly.
- **После 200 ставок + стабильный ROI 10 %**: можешь попробовать
  Aggressive с Quarter-Kelly.
- **Никогда** не прыгай сразу в Aggressive/Underdog без пристрелки.

## Почему value важнее коэф

Коэф 2.0 сам по себе ничего не говорит. Value 15 % говорит, что в
долгосрочной перспективе ты получаешь +15 копеек на каждый рубль ставки
**в среднем**. Это и есть математическое ожидание.

Одиночный матч — случайность. Серия из 100 матчей с +EV → детерминированная
прибыль (с флуктуациями).

## Типичные ошибки

- Переоценка p на отбеленных рынках (где букмекеры очень точны).
- Игнорирование cross-correlation ставок (два исхода, которые коррелируют).
- Chasing losses — ставить больше после провала, чтобы "отыграться".
- Gambler's fallacy — "не выпадало X раз подряд, значит теперь выпадет".

Все эти ловушки устраняются автоматически дисциплиной — соблюдай план.
